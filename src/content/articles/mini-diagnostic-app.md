A MINI diagnostic app should be selected by the job and exact vehicle, not a generic works-with-MINI claim. BimmerLink, BimmerCode and Carly overlap around BMW Group vehicles but document different centers of gravity, adapter paths and license models.

## Shortlist by documented role

| Buyer field | BimmerLink | BimmerCode | Carly |
| --- | --- | --- | --- |
| Main job | BMW/MINI diagnostics and service | Coding and customization | Multi-brand app/scanner package |
| MINI scope | Broad MINI support from 2006+, subject to vehicle/function | Exact MINI models and coding options listed | MINI is a core brand; features vary by model/build |
| Diagnostics / live data | Control-unit diagnostics, real-time values and CSV logging documented | Not a general diagnostic substitute | Manufacturer-specific access needs applicable license and vehicle selection |
| Service functions | Battery registration, service reset, parking-brake mode and qualified diesel/DPF functions | Not the central service-tool claim | Verify each named function for the exact MINI |
| Coding | Not the central documented role | Supported where the exact vehicle/control-unit option is listed | Vehicle/package-specific |
| Adapter and OS | iOS/Android; follow supported-adapter path | iOS 13+/Android 6+; use current adapter table | Use Carly scanner/app path; verify phone and vehicle |
| Pricing / license | Verify current app-store price and region | Full version is platform-specific; verify store price | Annual package and hardware/configuration vary by location |

This is a current official-claim comparison, not a hands-on ranking. A category does not mean every module, parameter or procedure exists on every MINI.

## Match jobs to evidence

For a warning light, demand exact module diagnostics and code coverage. For live investigation, demand named parameters or module data. For battery registration, service reset or parking-brake work, demand the exact function and vehicle. For personalization, use a coding-specific options record rather than assuming a diagnostic license includes coding.

Generic emissions OBD can expose a narrower layer than manufacturer-specific MINI diagnostics. Carly explicitly distinguishes basic OBD from manufacturer-specific access; BimmerLink and BimmerCode likewise require a supported app/vehicle/adapter chain.

## Buying sequence

1. Record MINI model, generation, production year and equipment.
2. Name the module, data, service function or coding option.
3. Check exact vehicle/function on the current official app page.
4. Check supported adapter, connection method and iOS/Android requirement.
5. Record whether the license is one-time, platform-specific, annual or bundled with hardware.
6. Buy only after every row is confirmed; a return policy is not compatibility evidence.

## Safety and bottom line

This guide excludes immobilizer, key, odometer, emissions and unsafe ECU-modification procedures. For ordinary buying intent, BimmerLink is diagnostics/service-led, BimmerCode is coding-led, and Carly is a broader licensed app/scanner package. Exact MINI, function, adapter and platform evidence decides fit.
